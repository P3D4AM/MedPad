می‌خواهید MedPad را کجا نصب کنید؟

راهنمای نصب روی VPS (الان روی ویندوز هستید):
۱. کل پوشه‌ی بسته را به سرور منتقل کنید: scp -r . root@آی‌پی-سرور:/opt/medpad (یا با WinSCP)
۲. به سرور وصل شوید: ssh root@آی‌پی-سرور
۳. روی سرور اجرا کنید: cd /opt/medpad && bash install.sh — همان منو باز می‌شود؛ گزینه‌ی «سرور لینوکسی» را انتخاب کنید. Node.js از داخل بسته نصب می‌شود (آفلاین) و سرویس systemd ساخته می‌شود.
۴. پنل روی http://آی‌پی-سرور:3000 در دسترس است.
💡 همین بسته روی ویندوز و لینوکس کار می‌کند؛ چیز دیگری لازم نیست دانلود کنید.
📦 نصب MedPad روی این سیستم شناسایی شد — دیتابیس، فایل‌ها و تنظیمات حفظ می‌شوند و فقط فایل‌ها به‌روزرسانی می‌شوند.

نوع اتصال کلادفلر

راهنمای ساخت توکن (۵ قدم)
  1. به dash.cloudflare.com بروید ← My Profile ← API Tokens
  2. Create Token ← Create Custom Token
  3. دسترسی اول: Account → Cloudflare Tunnel → Edit
  4. دسترسی دوم و سوم: Zone → DNS → Edit و Zone → Zone → Read
  5. Continue ← Create ← توکن را کپی کنید و اینجا وارد کنید

🔒 توکن فقط برای ساخت تونل استفاده می‌شود و جایی ذخیره نمی‌شود.

🔒 قبل از هر تغییری، نصب‌کننده رکوردهای فعلی را فهرست و یک نسخه‌ی پشتیبان قابل بازیابی در tunnel-creds/ ذخیره می‌کند؛ رکوردهای تکراری فقط با تأیید شما جایگزین/حذف می‌شوند. اگر بدون تأیید نصب کنید، به حالت محلی برگردانده می‌شود.
