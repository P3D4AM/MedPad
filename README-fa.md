## 🔒 تغییرات امنیتی v1.9.12 (مهم)

این نسخه حاصل ممیزی کامل امنیتی است؛ **هیچ فیچری حذف نشده** و نصب آفلاین مثل قبل کار می‌کند:

1. **امنیت پروسه‌ها:** دیگر هیچ برنامه‌ی بی‌گانه‌ای روی پورت‌های MedPad کشته نمی‌شود. اگر برنامه‌ی دیگری پورت لازم را گرفته باشد، نصب‌کننده **با پیام خطای شفاف متوقف می‌شود** (راه‌حل: بستن آن برنامه یا انتخاب پورت دیگر با `--port` / `--rt-port`). توقف نسخه‌ی قبلی MedPad فقط با «اثبات مالکیت» انجام می‌شود (مسیر اسکریپت / زمان شروع پروسه) — PID بازیافتی هرگز کشته نمی‌شود.
2. **رمز عبور:** رمز پیش‌فرض `admin123` **کلاً حذف شد**. نصب عمومی (VPS/کلادفلر) بدون رمز قوی (حداقل ۱۰ کاراکتر شامل حرف و رقم) انجام نمی‌شود؛ نصب محلیِ تازه بدون رمز، یک **رمز تصادفی امن** می‌سازد و فقط یک‌بار روی صفحه نشان می‌دهد. هش رمزها از SHA-256 به **bcrypt** ارتقا یافت؛ کاربران قبلی بدون هیچ کاری می‌توانند وارد شوند و هششان در اولین ورود موفق خودکار به bcrypt تبدیل می‌شود.
3. **داده‌ی نمونه اختیاری شد:** حساب‌های نمونه (علی/سارا/مهلا با رمز 1234) فقط وقتی ساخته می‌شوند که صریحاً بخواهید (چک‌باکس در ویزارد یا `--with-sample-data`). پیش‌فرض: **خیر**.
4. **فایل‌های حساس:** `.env`، دیتابیس و `tunnel-creds/` فقط برای مالک فایل قابل خواندن‌اند (Linux: 600/700 — در هر ارتقا دوباره اعمال می‌شود؛ Windows: ACL با icacls تا حد ممکن). توکن دیگر در هیچ فایل `.bat` تولیدشده‌ای نوشته نمی‌شود.
5. **عملیات Cloudflare امن:** قبل از هر تغییر DNS، رکوردهای فعلی دقیق فهرست می‌شوند و طرح تغییر نمایش داده می‌شود؛ تغییر مخرب (حذف/جایگزینی رکورد) فقط با **تأیید صریح** انجام می‌شود، قبل از تغییر **نسخه‌ی پشتیبان قابل بازیابی** ذخیره می‌شود و خطای وسط کار، تغییرهای انجام‌شده را **برمی‌گرداند** (rollback).
6. **پورت سفارشی realtime در هر دو حالت:** پچ پورت `--rt-port` حالا مسیر بازنویسی (rewrite) های حالت gateway (فایل `server.js` مستقل + `routes-manifest.json`) را هم اصلاح می‌کند؛ قبلاً در حالت پروکسی هنوز 3003 می‌ماند. نصب‌های تونلی به حالت gateway سوییچ می‌کنند تا داشبورد از آدرس عمومی هم کار کند.

## 🆕 نصب در v1.9.12 — نسخه حساسیت‌بخشی امنیتی (v1.9.11 منوی تعاملی + نصب‌کننده گرافیکی مرورگری)

از این نسخه، با اجرای `install.bat` (یا `install.ps1`) یک **منو** باز می‌شود:

```
Q1 - می‌خواهید MedPad را کجا نصب کنید؟
  1) این کامپیوتر (نصب لوکال)
  2) سرور لینوکسی VPS (سرویس دائمی systemd)
  3) کلادفلر (نصب لوکال + آدرس عمومی HTTPS)

Q2 - نصب چطور انجام شود؟
  1) نصب‌کننده مرورگری (GUI) — پیشنهادی، صفحه خودکار باز می‌شود
  2) ویزارد داخل همین کنسول (CLI)
```

- **حالت مرورگری (GUI):** یک صفحه‌ی نصب فارسی **خودکار در مرورگر باز می‌شود**؛ همان سؤال‌ها را می‌پرسد، **نام کاربری و رمز مدیر و شماره پورت** (و برای کلادفلر: توکن و دامنه) را می‌گیرد، نصب را با **لاگ زنده** اجرا می‌کند و در پایان دکمه‌ی «استارت سرور و باز کردن پنل» دارد. پنجره‌ی کنسول را ببندید، ویزارد مرورگری به کارش ادامه می‌دهد.
- **حالت CLI:** همین سؤال‌ها داخل خود ترمینال پرسیده می‌شود.
- **استارت/استاپ سرور — هم CLI هم GUI:**
  - `start-server.bat` / `start.bat` (یا `start-server.sh`) → استارت
  - `stop-server.bat` / `stop.bat` (یا `stop-server.sh`) → استاپ
  - `server-manager.bat` (یا `server-manager.sh`) → **صفحه‌ی گرافیکی مدیریت سرور** با دکمه‌های استارت/استاپ/ری‌استارت و وضعیت زنده
- **بعد از هر استارت، صفحه‌ی اصلی پنل همیشه خودکار در مرورگر باز می‌شود** (این رفتار پیش‌فرض است).

### نصب در ویندوز (x64)

1. کل پوشه را **Extract** کنید (اگر از داخل zip اجرا کنید خطا می‌دهد)
2. روی `install.bat` دوبار کلیک کنید و UAC را تأیید کنید
3. اگر Node.js نصب نباشد، **خودکار و خاموش** از بسته نصب می‌شود
4. در منو، مقصد و حالت نصب را انتخاب کنید (پیشنهادی: مرورگری)
5. در پایان نصب، خود بپرسید «الان استارت شود؟» — با تأیید، پنل بالا می‌آید و صفحه‌اش باز می‌شود؛ یا هر وقت خواستید `start.bat` را دابل‌کلیک کنید
6. مرورگر: `http://localhost:3000` — ورود مدیر: `admin` / رمزی که وارد کردید (یا رمز تصادفی‌ای که نصب‌کننده یک‌بار نشان می‌دهد؛ دیگر رمز پیش‌فرض admin123 وجود ندارد)

> 📍 **نکته v1.9.7:** نصب داخل همان پوشه پکیج انجام می‌شود؛ `start.bat`، `stop-server.bat`، `server-manager.bat` و بقیه دقیقاً **کنار همان install.bat** ایجاد می‌شوند. اگر قبلاً نسخه v1.9.6 را نصب کرده‌اید و داده داشتید، خودکار از پوشه قدیمی `medpad-install` منتقل می‌شود.

### نصب در لینوکس (x64)

```bash
unzip medpad-offline-v1.9.12.zip
cd medpad-offline-1.9.12
bash install.sh          # منو باز می‌شود — همان گزینه‌ها
./start-server.sh        # استارت + باز شدن خودکار پنل در مرورگر
./server-manager.sh      # مدیریت گرافیکی (استارت/استاپ/ری‌استارت)
```

> ⚠️ **کاربران ویندوز:** نصب با `install.bat` انجام می‌شود (دابل‌کلیک). اگر install.sh را داخل Git Bash اجرا کنید، خودش تشخیص می‌دهد و شما را به install.bat هدایت می‌کند.

اگر Node.js نصب نباشد، از `offline/node-*.tar.xz` داخل پوشه `runtime/` استخراج می‌شود.
(نیازمند `xz-utils` برای استخراج — در اوبونتو معمولاً هست)

### نصب روی سرور لینوکسی (VPS)

روی سرور: بسته را آپلود کنید (`scp -r . root@SERVER:/opt/medpad`)، بعد `bash install.sh` و انتخاب گزینه‌ی «سرور لینوکسی». سرویس‌های **systemd** ساخته می‌شوند (`medpad-panel` + `medpad-realtime` + در صورت دامنه، `medpad-tunnel`) تا پنل با بوت سرور خودکار بالا بیاید و در صورت کرش ری‌استارت شود. اگر با root اجرا کنید، خودکار نصب و فعال می‌شوند؛ در غیر این صورت دستور `sudo cp` چاپ می‌شود. اگر همین منو را روی **ویندوز** با گزینه VPS باز کنید، راهنمای گام‌به‌گام انتقال بسته به سرور نمایش داده می‌شود.

### ویزارد مرورگری روی سرور بدون مانیتور (headless)

ویزارد فقط روی `127.0.0.1` گوش می‌دهد (امنیت). روی VPS بدون دسکتاپ، از لپ‌تاپ خودتان با تونل SSH بازش کنید:

```bash
ssh -L 3199:localhost:3199 root@SERVER
# بعد در لپ‌تاپ: http://localhost:3199
```

## فایل‌های مهم بعد از نصب

| فایل | کار |
|------|-----|

| `install.bat` / `install.sh` | اجرای دوباره = به‌روزرسانی (داده‌ها حفظ می‌شوند) |
